# 문어 키우기

## 대상 사용자
* 쉬는 시간에 노트북이나 휴대폰 브라우저로 잠깐씩 화면을 켜 두고 가볍게 즐길 본인(1인 사용자).

## 사용 목적
* 화면 속 문어에게 밥을 주고 놀아 주는 단순한 상호작용을 통해 짧은 휴식 시간 동안 기분 전환을 하기 위함.

## 화면 구성과 동작
* **레이아웃**: 노트북과 모바일 화면 모두에서 보기 편한 중앙 정렬 구성.
* 제목 아래 안내: 10초마다 배부름이랑 기분이 5씩 줄고 하나라도 0이 되면 문어가 떠난다는 한 줄이 나옴. (써 본 사람 질문 보고 더함)
* **문어 표시 영역 (화면 중앙)**: 상태에 따라 4가지 모습으로 변화함.
  * **웃는 문어**: 배부름과 기분이 **모두 70 이상**일 때 다리를 들고 웃는 모습.
  * **우는 문어**: 배부름과 기분 중 **하나라도 30 미만**(1~29)일 때 다리가 축 처지고 우는 모습.
  * **보통 문어**: 위 조건에 해당하지 않는 평상시 모습(예: 초기 상태인 50, 50).
  * **떠난 상태 (게임 오버)**: 배부름과 기분 중 **하나라도 0**이 되면 문어 자리에 빈 점선 테두리만 남고, "문어가 떠났습니다"라는 안내 문구가 표시됨.
* **상태 표시 영역 (문어 아래)**:
  * **배부름**과 **기분** 두 가지 수치를 막대(Progress bar)와 숫자로 함께 표시.
  * 범위는 최소 $0$에서 최대 $100$이며, 시작 시 초기값은 각각 $50$, $50$으로 설정.
* **시간 경과 동작**:
  * $10$초마다 배부름과 기분 수치가 자동으로 $5$씩 감소함 (최소 $0$까지만 감소).
* **조작 버튼 영역 (화면 하단)**:
  * **밥 주기 버튼**: 클릭 시 배부름 $+20$ (최대 $100$을 넘지 않음).
  * **놀아 주기 버튼**: 클릭 시 기분 $+20$ (최대 $100$을 넘지 않음).
  * 다시 키우기 버튼: 평소엔 안 보이고 문어가 떠났을 때만 나타남. 누르면 50, 50으로 처음부터 다시 시작. (처음부터 회색 버튼이 있어서 이상해서 고침)

## 필요한 자료
* **단일 HTML 파일 (`문어.html`)**: HTML 구조, CSS 스타일, JavaScript 동작 코드를 파일 하나에 통합.
* **내장 그래픽 (인라인 SVG 또는 CSS 그래픽)**: 외부 이미지 파일 없이 HTML 코드 내부에 직접 그린 3종류의 문어 그림(웃음, 보통, 울음)과 빈자리 점선 표현.
* **시스템 기본 글꼴**: 인터넷 글꼴(웹폰트)을 불러오지 않고 기기 내장 기본 글꼴 사용.

## 완료 기준
(AI가 쓴 건 너무 뭉뚱그려져 있어서 뭘 누르면 뭐가 나오는지로 직접 고침)
* 처음 열면 배부름 50, 기분 50에 보통 문어가 나옴. 제목 아래에 줄어드는 규칙 안내가 보임.
* 밥 주기를 한 번 누르면 배부름이 20 오름. 100일 때 또 눌러도 100 그대로임.
* 아무것도 안 누르고 10초 기다리면 배부름이랑 기분이 둘 다 5씩 줄어 있음.
* 둘 다 70 이상으로 올리면 다리 든 웃는 문어, 그냥 둬서 30 밑으로 내려가면 우는 문어가 됨.
* 처음엔 다시 키우기 버튼이 안 보임. 하나라도 0이 되면 문어 자리에 점선만 남고 문어가 떠났다는 말과 다시 키우기 버튼이 나옴. 밥 주기, 놀아 주기는 안 눌림. 다시 키우기를 누르면 50, 50으로 돌아감.
* 다른 파일이나 로그인 없이 HTML 파일 하나로 열리고, 휴대폰에서도 문어랑 숫자, 버튼이 한 화면에 보임. 작은 휴대폰에서 문어가 떠났을 때도 다시 키우기 버튼까지 보임.

## 추가 기능
* 문어 이름 짓기 기능
* 브라우저 창을 닫아도 데이터가 유지되는 자동 저장 기능 (`LocalStorage` 활용)
* 시간에 따른 문어의 성장 단계 변화
* 재우기(수면) 기능
* 문어가 화면에서 돌아다님
* 건강한 상태라면 문어가 가만히 있을때도 머리에 광택이 생기고 그것들이 2프레임정도로 움직이며 반짝임을 표시 - 사용자 성취감 자극

## 한계 및 비목표
1. **외부 리소스 미사용**: 별도의 이미지 파일(`.png`, `.jpg` 등)이나 외부 인터넷 글꼴(웹폰트), 외부 라이브러리를 일절 사용하지 않는다.
2. **상태 저장 미지원**: 현재 버전에서는 브라우저를 새로고침하거나 창을 닫으면 진행 상태가 초기화되며, 데이터를 영구 저장하지 않는다.
3. **단순 상호작용 유지**: 성장, 수면, 이름 짓기 등 복잡한 육성 시스템은 현재 개발 범위에서 제외하고 '밥 주기'와 '놀아 주기' 두 가지 핵심 동작에만 집중한다.

## 검증 방법
1. 페이지를 열면서 휴대폰 스톱워치를 같이 켜고, 밥 주기를 한 번 누른 뒤 35초쯤 됐을 때 화면 숫자를 내가 계산한 값(배부름 50+20-15=55, 기분 50-15=35)이랑 비교
