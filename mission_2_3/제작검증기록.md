## 수정 기록
고칠 때는 Gemini 새 대화에 `문어_v1.html` 주고 한 번에 하나씩 고쳐 달라고 함

### 수정 기록 1
- 발견한 문제: 작은 휴대폰 크기로 창을 줄이고 문어가 떠날 때까지 둬 봄(테스트 내용). 다시 키우기 버튼까지 한 화면에 보일 줄 알았는데(예상 결과) 버튼이 화면 아래로 잘려서 내려야 보였음(실제 결과)
- AI에게 전달한 요청: 작은 휴대폰 크기로 창을 줄여서 문어가 떠날 때까지 둬 봤는데, 다시 키우기 버튼이 화면 아래로 잘려서 안 보여. 아래로 내려야 보여. 기획서에는 휴대폰에서도 문어랑 숫자, 버튼이 한 화면에 보인다고 적었어. 이 부분만 고치고, 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘.
- 저장한 버전: `문어_v1.html` → `문어_v2.html`
- 수정 후 테스트 결과: 같은 크기로 다시 해 보니 문어가 떠나도 다시 키우기 버튼까지 다 보임. 35초 숫자 확인도 다시 해 봤는데 55, 35 그대로.
- 수정 이유: 작은 폰에선 문어가 떠났는데 다시 키우는 버튼이 안 보여서 끝난 줄 앎.

### 수정 기록 2
- 발견한 문제: 처음 열었을 때(테스트 내용) 버튼은 밥 주기, 놀아 주기만 있을 줄 알았는데(예상 결과) 회색 다시 키우기 버튼이 있어서 눌러 봤더니 아무 일도 없었음(실제 결과).
- AI에게 전달한 요청: 처음 열었을 때부터 회색 다시 키우기 버튼이 있으니까 이상하다. 문어가 죽었을 때만 그 버튼이 자연스럽게 나타나도록 해 줘. 다른 건 그대로 두고, 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘
- 저장한 버전: `문어_v2.html` → `문어_v3.html`
- 수정 후 테스트 결과: 처음엔 다시 키우기 버튼이 안 보이고, 문어가 떠나니까 나타남. 누르니 50, 50으로 돌아가고 버튼은 다시 사라짐. 작은 화면에서 버튼 보이는 것도 그대로
- 수정 이유: 안 눌리는 버튼이 처음부터 있으면 고장 난 줄 앎

### 수정 기록 3
- 발견한 문제: 사용자 테스트에서 써 보게 했더니(테스트 내용) 그냥 알아서 키울 줄 알았는데(예상 결과) 숫자가 왜 빨리 주는지, 계속 켜 둬야 하는지, 0이 되면 어떻게 되는지 물어봄(실제 결과).
- AI에게 전달한 요청: 써 본 사람이 숫자가 왜 이렇게 빨리 줄어드는지, 화면을 계속 켜 둬야 하는지, 0이 되면 어떻게 되는지 물어봤어. 제목 아래에 10초마다 배부름이랑 기분이 5씩 줄고, 하나라도 0이 되면 문어가 떠난다는 안내를 한 줄 넣어 줘. 작은 휴대폰에서도 버튼까지 한 화면에 보이는 건 그대로 두고, 다른 것도 그대로 둔 채 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘.
- 저장한 버전: `문어_v3.html` → `문어_v4.html` (이걸 `문어.html`로 냄)
- 수정 후 테스트 결과: 제목 아래에 안내 한 줄이 나옴. 작은 휴대폰에서 문어가 떠나도 다시 키우기 버튼까지 보임. 35초 숫자도 55, 35 그대로
- 수정 이유: 규칙을 모르면 금방 우는 문어만 보고 왜 그런지 몰라서 그냥 끔

## 사용자 테스트
- 테스트 참여자와 요청한 작업: 사용법 모르는 claude 새 대화에 `문어_v3.html`만 주고 휴대폰 화면으로 문어 좀 키워 보라고만 함.
- 사용자의 행동과 질문: 밥 주기, 놀아 주기 눌러서 웃는 문어 봄. 그냥 1분 두니 20, 20에 우는 문어 됨. 밥 계속 눌러서 100에서 멈추는 것도 봄. 다시 열면 처음부터냐, 계속 켜 둬야 하냐, 0 되면 어떻게 되냐고 물어봄
- 받은 피드백: 귀엽고 바로 알겠는데 금방 우울해지고 다시 열면 처음부터라 키우는 느낌이 약하다. 줄어드는 속도를 늦추거나 기록이 남았으면 좋겠다.
- 반영 내용과 결과: 제목 아래에 안내 한 줄 넣음(수정 기록 3). 속도는 바꾸면 35초 확인이 안 맞아서 그대로 둠. 기록 남기는 건 원래 추가 기능에 있어서 나중에.
