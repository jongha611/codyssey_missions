# 미션 1 기록

- AI A 이름 / 주요 대화 캡처 파일명: gemini / `gemini_chat_history.png`
- AI B 이름 / 주요 대화 캡처 파일명: claude / `claude_chat_history.png`
- AI가 물어서 내가 정한 것:
  - 나 혼자 내 컴퓨터 브라우저에서 바로 열어서 쓸 거라고 정함
  - 티어 등급은 제일 익숙한 S, A, B, C, D 5개로 정함
  - 영화는 유명한 거 12개 먼저 넣어두고, 내가 직접 제목이랑 사진을 추가할 수 있게 해달라고 정함
  - 다 만든 다음 '이미지 저장' 버튼을 누르면 사진(PNG)으로 바로 다운로드되게 해달라고 정함
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):
  - 해본 행동: AI A(gemini)와 AI B(claude)에 똑같은 주문("웹페이지 하나로 다 만들어줘, 설치 없이 그냥 더블클릭하면 열리게 해줘")을 넣고, 나온 결과 파일(`영화_A_초안.html`, `영화_B_초안.html`)을 더블클릭해서 직접 써봄.
  - 기대 결과: 아무 프로그램 안 깔아도 인터넷 창에서 바로 열리고, 마우스로 영화를 끌어다 놓을 수 있고, 사진으로 깨끗하게 저장되어야 함.
  - A의 결과 (`영화_A_초안.html`):
    - 열리기도 잘 열리고 마우스로 끌어다 놓는 것도 됨.
    - 그런데 카드를 다른 영화들 사이에 끼워 넣을 수가 없고 무조건 맨 끝에만 붙어서 순서 바꾸기가 불편함.
    - '이미지 저장'을 눌렀을 때 나오는 사진 글씨가 살짝 흐릿함.
  - B의 결과 (`영화_B_초안.html`):
    - 카드를 원하는 자리 중간에 쏙 끼워 넣을 수 있어서 자리 배치가 훨씬 편함.
    - 카드를 옮길 때마다 화면 아래에 "어디로 옮겼다"고 안내 말풍선이 떠서 알아보기 쉬움.
    - '이미지 저장'을 눌렀을 때 글씨가 뭉개지지 않고 선명하게 저장됨.
- 선택한 파일명과 고른 이유:
  - 선택한 파일명: `영화_B_초안.html`
  - 고른 이유: 카드를 중간에 쏙 끼워 넣을 수 있어서 다루기 훨씬 편했고, 사진으로 저장했을 때도 글씨가 덜 깨지고 훨씬 선명해서.
