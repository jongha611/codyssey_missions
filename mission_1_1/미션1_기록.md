# 미션 1 기록

- AI A 이름 / 주요 대화 캡처 파일명: gemini / `gemini_chat_history.png`
- AI B 이름 / 주요 대화 캡처 파일명: claude / `claude_chat_history.png`
- AI가 물어서 내가 정한 것:
  - 나 혼자 내 컴퓨터 브라우저에서 열어서 씀
  - 등급은 익숙한 S, A, B, C, D 5개
  - 유명한 영화 12개를 먼저 넣고, 제목과 사진을 직접 추가할 수 있게 함
  - 이미지 저장 버튼을 누르면 사진(PNG)으로 내려받게 함
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):
  - 해본 행동: 두 AI에 같은 기획서를 주고 받은 파일(`영화_A_초안.html`, `영화_B_초안.html`)을 더블클릭해서 써 봄
  - 기대 결과: 설치 없이 바로 열리고, 영화를 끌어다 놓을 수 있고, 사진으로 깨끗하게 저장됨
  - A의 결과: 잘 열리고 끌어다 놓기도 됨. 그런데 카드가 영화들 사이에 안 끼워지고 맨 끝에만 붙음. 저장한 사진 글씨가 살짝 흐릿함
  - B의 결과: 카드를 원하는 자리 사이에 끼워 넣을 수 있음. 카드를 눌러서 옮기면 화면 아래에 어디로 옮겼는지 안내가 뜸. 저장한 사진 글씨가 선명함
- 선택한 파일명과 고른 이유:
  - 선택한 파일명: `영화_B_초안.html`
  - 고른 이유: 카드를 사이에 끼울 수 있어서 순서 정하기가 편했고, 저장한 사진도 더 선명해서
