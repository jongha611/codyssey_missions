# 영화 티어리스트 웹페이지 최종 기획서

## 1. 누가 쓰나 (Target User)
* **주요 대상**: 본인이 감상한 영화를 간편하게 등급별로 분류·기록하고 시각적인 이미지로 소장하거나 공유하려는 1인 사용자.
* **사용 환경**: 복잡한 회원가입이나 백엔드 서버 설정 없이, PC 및 모바일 웹 브라우저에서 단일 파일 실행만으로 즉시 이용할 수 있는 환경을 지향합니다.

---

## 2. 무엇을 하려고 (Purpose & Goal)
* **핵심 목표**: 영화 포스터 및 카드들을 5단계 티어에 배치하여 직관적인 티어표를 완성하는 반응형 웹 애플리케이션 제작.
* **주요 목적**:
  * 영화 카드들을 자유롭게 드래그하거나 클릭하여 원하는 등급으로 재배치.
  * 완성된 티어리스트를 단일 고해상도 이미지(PNG) 파일로 다운로드하여 개인 보관 및 SNS/커뮤니티 공유.

---

## 3. 화면과 동작 (UI & Interaction)

### (1) 화면 레이아웃
* **상단 헤더**: 서비스 제목 및 간단한 사용 가이드 문구.
* **컨트롤 패널**:
  * 영화 추가 입력 폼 (영화 제목, 개봉 연도/장르, 로컬 포스터 이미지 업로드).
  * 액션 버튼군 ('📷 이미지 저장', '↺ 초기화').
* **티어 보드 영역 (중앙)**:
  * 5개 표준 등급 행 구성: `S`(빨강), `A`(주황), `B`(노랑), `C`(초록), `D`(파랑).
  * 각 행은 좌측 '티어 라벨 박스'와 우측 '카드 배치 드롭존'으로 분할.
* **미분류 영화 보관함 (하단)**:
  * 아직 티어가 지정되지 않은 카드들을 보관하는 드롭존 및 남은 영화 개수 카운터.

### (2) 핵심 인터랙션 및 동작
* **드래그 앤 드롭 (Drag & Drop)**:
  * 마우스 드래그를 통해 카드들을 티어 행 사이 또는 미분류 보관함으로 자유롭게 이동.
  * 드래그 중인 카드는 반투명 처리되며, 올바른 드롭 영역 진입 시 시각적 테두리 하이라이트 제공.
* **클릭 기반 빠른 이동 (Quick Move Dialog)**:
  * 모바일 터치 환경 및 드래그가 어려운 사용자를 위해 카드를 클릭하면 등급 선택 팝업창 표시.
  * 팝업에서 티어 버튼(`S`~`D`, `보관함`)을 누르면 즉시 해당 위치로 카드 이동.
* **영화 카드 추가 및 삭제**:
  * 제목과 선택적 이미지 파일을 등록하면 즉시 미분류 보관함에 새 카드 생성.
  * 카드 우측 상단 '×' 버튼을 통해 개별 카드 즉시 삭제.
* **무의존성 PNG 이미지 렌더링**:
  * '이미지 저장' 클릭 시 브라우저 내장 Canvas 2D API가 현재 티어 상태를 그려 `영화_티어리스트_YYYYMMDD.png` 파일로 즉시 자동 다운로드.

## 4. 필요한 자료 (Required Data & Tech Stack)

### (1) 데이터 및 에셋
* **기본 프리셋 영화 (12편)**:
  * 첫 접속 시 즉시 배치를 체험해 볼 수 있도록 대중적인 영화 12편(기생충, 올드보이, 살인의 추억, 다크 나이트, 인셉션, 인터스텔라, 신세계, 헤어질 결심, 매트릭스, 센과 치히로, 탑건: 매버릭, 글래디에이터) 기본 제공.
  * 외부 이미지 링크 끊김 방지를 위해 장르별 고유 그라디언트 카드 스타일 내장.
* **사용자 정의 데이터**:
  * 사용자가 직접 등록하는 영화 제목, 부가정보(연도/장르), 브라우저 로컬 이미지 파일(FileReader API를 통한 Data URL 인코딩).

### (2) 기술 스택 및 아키텍처
* **완전 자립형 단일 파일 (Single-File Architecture)**:
  * 별도 CSS/JS 파일 분리 없이 단 하나의 `.html` 파일 내에 구조, 스타일, 인터랙션 로직 전체 내장.
* **외부 종속성 배제 (Zero External Dependency)**:
  * 외부 CDN(폰트, CSS 프레임워크, JS 라이브러리)이나 유료/키 기반 검색 API 연동 없이 브라우저 기본 표준 기능(HTML5, CSS3, Vanilla JS, Canvas API, LocalStorage)만으로 구성.

---

## 5. 완성 기준 (Definition of Done)

1. **단독 구동성**: 네트워크 연결이 없는 오프라인 환경에서도 `.html` 파일 더블클릭만으로 모든 기능이 정상 실행되어야 한다.
2. **배치 인터랙션**: PC 환경의 마우스 드래그 앤 드롭 및 모바일 팝업 클릭을 통한 카드 이동이 끊김 없이 매끄럽게 동작해야 한다.
3. **데이터 지속성 (`LocalStorage`)**: 새로고침이나 브라우저 재실행 후에도 사용자가 수정한 티어 배치 상태가 그대로 유지되어야 한다.
4. **이미지 출력 품질**: '이미지 저장' 버튼 클릭 시 티어 보드 레이아웃과 영화 텍스트/이미지가 깨짐 없이 선명한 PNG 파일로 내려받아져야 한다.
5. **초기화 안전성**: '초기화' 버튼 클릭 시 확인 알림창을 띄우고, 승인 시 로컬 스토리지를 비우고 초기 12편의 프리셋 상태로 정확히 복원되어야 한다.
