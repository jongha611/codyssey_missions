# 나만의 미니 펫 키우기

## 대상 사용자
* 쉬는 시간에 노트북이나 스마트폰 웹 브라우저로 가볍게 켜서 플레이하는 본인(1인 사용자).

## 사용 목적
* 화면 속 작은 펫에게 밥을 주고 놀아 주는 단순하고 직관적인 상호작용을 통해 짧은 휴식 시간 동안 기분을 전환함.

## 화면 구성과 동작
* **레이아웃 (모바일 및 PC 겸용)**
  * **상단/중앙**: 펫의 현재 기분과 상태를 나타내는 얼굴(이모지)과 상태 메시지 표시.
  * **중단**: '배부름'과 '기분' 두 가지 상태를 숫자와 막대그래프(Progress Bar)로 나란히 또는 위아래로 표시.
  * **하단**: 상호작용 버튼 영역 (`밥 주기`, `놀아 주기`, 그리고 종료 시 활성화되는 `다시 키우기`).
* **상태 수치 및 변화 규칙**
  * **초기값 및 범위**: 배부름과 기분 모두 최소 0에서 최대 100의 범위를 가지며, 시작 시 초기값은 각각 50으로 설정.
  * **버튼 동작**:
    * `밥 주기` 클릭 시: 배부름 +20 (최대 100을 넘지 않음).
    * `놀아 주기` 클릭 시: 기분 +20 (최대 100을 넘지 않음).
  * **시간 경과 동작**: 10초마다 배부름과 기분 수치가 동시에 5씩 감소 (최소 0 미만으로 내려가지 않음).
* **표정(이모지) 변화 조건**
  * **웃는 얼굴 (😄)**: 배부름과 기분이 **모두 70 이상**일 때.
  * **우는 얼굴 (😢)**: 배부름과 기분 중 **하나라도 30 미만**(1~29)일 때.
  * **보통 얼굴 (🙂)**: 위 두 조건에 해당하지 않는 나머지 경우.
* **종료 및 재시작 동작**
  * **게임 종료**: 배부름과 기분 중 **하나라도 0이 되면** 펫이 떠났다는 안내 문구(예: "펫이 떠났습니다...")를 표시하고, `밥 주기`와 `놀아 주기` 버튼을 비활성화(클릭 불가)하며 타이머를 멈춤.
  * **다시 키우기**: `다시 키우기` 버튼을 누르면 배부름과 기분이 다시 50, 50으로 초기화되고 버튼과 타이머가 정상 작동하며 처음부터 다시 시작함.

## 필요한 자료
* **단일 파일**: 별도 서버나 외부 파일 연결 없이 단독으로 실행되는 `index.html` 파일 1개 (HTML, CSS, JavaScript 포함).
* **그래픽 및 글꼴**: 외부 그림 파일이나 인터넷 글꼴(웹 폰트)을 일절 사용하지 않고, 기기 기본 글꼴과 시스템 기본 이모지(🙂, 😄, 😢, 👋 등) 및 CSS 도형(막대그래프)만 활용.

## 완료 기준
(AI가 쓴 건 한 줄에 다 뭉쳐 있어서 뭘 누르면 뭐가 나오는지로 직접 고침)
* 처음 열면 배부름 50, 기분 50에 보통 얼굴이 나옴.
* 밥 주기를 한 번 누르면 배부름이 20 오름. 100일 때 또 눌러도 100 그대로임.
* 아무것도 안 누르고 10초 기다리면 배부름이랑 기분이 둘 다 5씩 줄어 있음.
* 둘 다 70 이상으로 올리면 웃는 얼굴, 그냥 둬서 30 밑으로 내려가면 우는 얼굴이 됨.
* 하나라도 0이 되면 펫이 떠났다는 말이 나오고 밥 주기, 놀아 주기가 안 눌림. 다시 키우기를 누르면 50, 50으로 돌아감.
* 다른 파일이나 로그인 없이 HTML 파일 하나로 열리고, 휴대폰에서도 얼굴이랑 숫자, 버튼이 한 화면에 보임.

## 추가 기능
* 펫 이름 짓기 및 화면 표시 기능.
* 브라우저 창을 닫거나 새로고침해도 현재 상태가 유지되는 저장 기능(`localStorage`).
* 생존 시간이나 조건에 따라 펫의 모습이 변하는 성장(진화) 기능.
* 펫 재우기 버튼 및 피로도 상태 추가.

## 한계 및 비목표
1. 브라우저 창을 닫거나 새로고침하면 진행 상태가 저장되지 않고 처음 상태(50, 50)로 초기화됨.
2. 외부 이미지 파일, 인터넷 글꼴(웹 폰트), 배경음악 및 효과음은 사용하지 않음.
3. 이름 짓기, 펫의 성장(진화), 재우기 등 복잡한 육성 요소는 현재 버전에서 구현하지 않음.

## 검증 방법
(AI는 이것저것 다 넣어 놔서 하나로 줄임)
1. 페이지를 열면서 휴대폰 스톱워치를 같이 켜고, 밥 주기를 한 번 누른 뒤 35초쯤 됐을 때 화면 숫자를 내가 계산한 값(배부름 50+20-15=55, 기분 50-15=35)이랑 비교함.
