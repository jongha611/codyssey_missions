# 미션 3 기록

## 받은_피드백.md 열기 전에 먼저 해 본 것

기획서의 완성 기준을 한 줄씩 해 봤다

- 한 칸에만 있고 옮긴 칸에 남기: 기생충을 누르고 S를 누름 → S칸으로 감. 다시 A를 누르니 A칸에만 있음. 끌어서 놓기도 됨. 결과: 됨
- 제목 입력하면 카드 생기기: 해리 포터를 추가 → 카드 생김. 결과: 됨 (그런데 빈칸으로 추가를 눌러도 빈 카드가 생김)
- 다시 열어도 남기: 기생충을 A칸에 두고 탭을 닫았다가 다시 염 → 전부 미분류로 돌아감. 결과: 안 됨
- 좁은 화면: 브라우저 창을 휴대폰 크기 정도로 줄임 → 오른쪽이 잘려 추가, 처음으로 버튼이 안 보이고 옆으로 밀어도 안 움직임. 결과: 안 됨
- 처음으로: 듄을 추가하고 기생충을 S칸에 둔 뒤 누름 → 처음 8개만 미분류로 돌아오고 듄은 없어짐. 결과: 됨
- HTML 한 장으로 열기: 파일 하나만 열었는데 다 나왔고 로그인도 없음. 결과: 됨
