# 미션 3 기록

## 받은_피드백.md 열기 전에 먼저 해 본 것

`민수_기획서.md`의 완성 기준을 한 줄씩 직접 해 봤다.

- **영화가 한 칸에만 있고, 옮긴 칸에 남는다** → '기생충'을 누르고 S 글자를 누름 → S칸으로 옮겨지고 아래 목록에서는 없어짐. 다시 '기생충'을 누르고 A를 누르니 S칸에서 빠지고 A칸에만 있음. '센과 치히로의 행방불명'은 끌어서 B칸에 놓아 봄 → 잘 옮겨짐. **됨.**
- **제목을 입력하면 새 영화 카드가 생긴다** → '해리 포터'를 쓰고 '추가'를 누름 → 아래 목록에 카드가 생김. **됨.** 그런데 아무것도 안 쓰고 '추가'를 누르니 글자 없는 빈 카드가 생기고 "‘’를 추가했어요"라고 나옴. 띄어쓰기만 넣고 눌러도 똑같이 빈 카드가 생김.
- **같은 파일을 다시 열어도 영화와 등급이 남는다** → '기생충'을 A칸에 옮겨 두고 탭을 닫았다가 같은 브라우저에서 파일을 다시 염 → 전부 미분류로 돌아가 있음. 추가한 '해리 포터'도 없어짐. **안 됨.**
- **화면 폭이 좁아져도 오른쪽이 잘리지 않는다** → 브라우저 창을 휴대폰 화면 정도로 좁게 줄여 봄 → 오른쪽이 잘려서 '추가', '처음으로' 버튼과 위쪽 '8편 중 0편 나눔'이 안 보임. 제목 글자 끝도 잘림. 옆으로 밀어 봐도 화면이 안 움직임. **안 됨.**
- **'처음으로'를 누르면 처음 영화 8개가 모두 미분류로 돌아간다** → '기생충'을 S칸에 두고 '듄'을 추가한 다음 '처음으로'를 누름 → 처음 8개가 다 미분류로 돌아오고 '듄'은 없어짐. **됨.**
- **외부 파일이나 로그인 없이 HTML 한 장으로 열린다** → 파일 하나만 열었는데 화면이 다 나왔고 로그인하라는 것도 없었음. **됨.**
- 그 밖에 해 본 것: '기생충'을 한 번 더 추가해 보니 '기생충' 카드가 2장이 됨.

- 아무도 말하지 않았는데 내가 찾은 것:
  - 브라우저 창을 휴대폰 화면 정도로 좁히면 오른쪽이 잘리고, 옆으로 밀어도 안 움직인다. '추가'와 '처음으로' 버튼이 아예 안 보여서 영화를 추가할 수도 없다. 기획서 완성 기준의 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다"와 다르다. AI는 "세 가지 외에는 잘 지킨다"고 했고, 동료는 "휴대폰으로 열어 보니 좀 불편했다"고만 했다.
  - 띄어쓰기만 넣고 '추가'를 눌러도 빈 카드가 생긴다. (AI는 제목을 비운 경우만 말함)
  - 같은 제목을 두 번 추가하면 같은 영화 카드가 2장 생긴다. 기획서에 같은 제목 이야기는 없고 일부러 두 번 넣을 일은 드물 것 같아서 피드백에는 넣지 않았다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:
  - 이야기하고 싶은 내용: AI가 말한 것 중 하나('처음으로'가 추가한 영화를 안 지운다)는 직접 해 보니 틀렸고, AI가 "잘 지킨다"고 한 곳에서도 문제(좁은 화면)가 나온 것.
  - 이유: AI 답이 그럴듯해서, 직접 해 보지 않았으면 틀린 말을 그대로 민수 님께 전하고 진짜 문제는 빠뜨렸을 것 같아서.
