# 민수 님께 보내는 피드백

잘된 점: 카드를 누르고 S를 누르면 바로 옮겨지고, 아래에 S에 놓았다는 안내가 떠서 잘 됐는지 바로 알 수 있었습니다. 등급마다 색이 달라서 칸 구분도 쉬웠고, 처음으로를 누르니 추가한 영화까지 지워지고 처음 8개로 잘 돌아왔습니다.

고치면 좋을 점
1. 본 것: 기생충을 A칸에 두고 탭을 닫았다가 다시 열었더니 모든 영화가 미분류로 돌아왔습니다.
   기준: 기획서 완성 기준의 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남는다는 조건
   제안: 옮긴 배치가 저장돼서 다시 열어도 그대로 남으면 좋겠습니다.

2. 본 것: 브라우저 창을 휴대폰 크기 정도로 줄였더니 오른쪽이 잘려 추가, 처음으로 버튼이 안 보였고, 옆으로 밀어도 움직이지 않았습니다.
   기준: 기획서 완성 기준의 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있다는 조건
   제안: 창이 좁아지면 화면도 같이 줄어들어서 버튼까지 다 보이면 좋겠습니다.

3. 본 것: 제목 칸을 비워 두고 추가를 눌렀더니 글자 없는 카드가 생겼습니다.
   기준: 기획서에는 없지만 쓰다가 불편했던 점입니다. 무슨 영화인지 모르는 카드가 남습니다.
   제안: 제목이 비어 있으면 카드를 만들지 말고 제목을 입력해 달라고 알려 주면 좋겠습니다.
